# Matrix Operations (Class 12 NCERT Style)

This project demonstrates **matrix operations** using Python and NumPy, following the **Class 12 Mathematics syllabus** (Matrices & Determinants chapter).

---

## ✅ Topics Covered
1. **Basic Operations**
   - Addition, Subtraction
   - Scalar Multiplication
   - Matrix Multiplication
   - Transpose of a matrix

2. **Special Matrices**
   - Identity Matrix
   - Zero Matrix
   - Diagonal Matrix

3. **Determinants**
   - Determinant of 2×2 and 3×3 matrices

4. **Inverse of a Matrix**
   - Formula: \( A^{-1} = \frac{1}{|A|} \cdot \text{adj}(A) \)
   - Verification: \( A \cdot A^{-1} = I \)

5. **Symmetric & Skew-Symmetric Matrices**
   - \( A = \frac{A + A^T}{2} + \frac{A - A^T}{2} \)

6. **Trace & Rank**
   - Trace = sum of diagonal elements
   - Rank = number of independent rows/columns

7. **Eigenvalues & Eigenvectors**
   - Solve \( |A - \lambda I| = 0 \)
